# Security policy

This project connects a local MCP server to a visible terminal. Treat it as a developer tool, not as a security boundary.

Do not send passwords, API keys, OAuth codes, participant responses, production data, or private repository contents to AGY/Gemini through this bridge.

If you discover a security issue, do not post credentials or an exploit containing private data in a public issue. Contact the repository owner through GitHub or use a private security advisory when available. Include a minimal reproduction and remove all secrets from the report.
